# 김호랑 웹사이트 리뉴얼 초안

기존 HTML의 브랜드 색상과 문의 이메일을 이어받아 만든 한국어 중심의 캐릭터·작품 소개 사이트입니다. 프레임워크, 패키지 설치, 유료 폰트, 외부 스크립트 없이 작동합니다. 실제 kimhorang.com이나 GitHub 저장소에는 적용하지 않았습니다.

## 파일

- `index.html`: 화면 구성, 소개 문구, 검색·공유 메타데이터
- `style.css`: PC·모바일 디자인
- `script.js`: 모바일 메뉴, 작품 필터, 작업 설명 창, 외부 판매처 링크 설정
- `assets/`: 기존에 제작한 캐릭터 배너, 호기 디자인 목업, 임시 파비콘

## 초안에 사용한 콘텐츠

- 김호랑 & 호기 배너와 호기 봉제인형 목업은 이전에 만든 이미지를 임시 사용했습니다. 최종 캐릭터 원화로 교체할 수 있습니다.
- 봉제인형 이미지는 AI 디자인 목업이며, 실제 제품 사진이 아닙니다. 카드와 상세 설명에도 목업임을 표시했습니다.
- ‘호기로운 하루’는 제작 중인 이모티콘으로 표시했습니다. 노란 제목 이미지는 사이트용 타이포그래피이며 실제 이모티콘 시안이 아닙니다.
- ‘호기록’은 기획 중으로 표시했습니다. 출시·연재를 완료했다는 문구는 넣지 않았습니다.
- 인스타그램은 `kimhorang`, 유튜브는 `@kimhorang711`, 이메일은 기존 코드에 있던 `contact@kimhorang.com`을 사용했습니다. 게시 전에 실제 운영 주소와 이메일 수신 여부를 확인하세요.
- 로고는 임시 글자 로고입니다. 최종 로고 원본을 받으면 교체할 수 있습니다.
- 실제 스토어 URL은 제공되지 않았으므로 링크를 만들지 않았습니다. ‘준비 중’으로 표시합니다.

## 미리 보기

압축을 풀고 `index.html`을 브라우저로 열면 됩니다. 모든 이미지와 파일은 상대 경로이므로 폴더 구조를 유지하세요. 로컬 서버를 사용하려면 이 폴더에서 `python3 -m http.server 8765`를 실행하고 `http://localhost:8765`에 접속하세요.

## 링크 수정

`script.js` 맨 위 `SITE`에서 SNS, 이메일, 스토어 URL을 수정하세요. 스토어 URL을 비워두면 판매처 링크는 표시하지 않습니다. 실제 HTTPS URL을 넣으면 링크가 나타납니다. 이메일을 변경하면 `index.html`의 기본 mailto 주소도 함께 바꿔야 JavaScript를 끈 경우에도 반영됩니다.

## GitHub Pages에 적용할 경우

1. 현재 저장소를 먼저 백업하거나 별도 브랜치에서 확인하세요.
2. 현재 Pages 게시 폴더(root 또는 docs)에 `index.html`, `style.css`, `script.js`, `assets`를 넣습니다. README를 업로드할 필요는 없습니다.
3. 기존 `CNAME`, DNS 설정, Pages 배포 설정, 다른 파일은 그대로 유지합니다. 이 초안에는 도메인 설정 변경을 포함하지 않았습니다.
4. PC와 모바일 화면, SNS, 이메일, 이미지 경로를 확인합니다.
5. 공유 이미지 주소는 `https://kimhorang.com/assets/kimhorang-hogi.png`입니다. 도메인을 바꾸면 `index.html`의 OG 메타데이터도 수정하세요.

## 판매 기능과 호스팅

GitHub Pages 공식 문서는 온라인 사업·전자상거래 또는 상거래 촉진이 주목적인 사이트 운영을 제한합니다. 외부 결제 링크만 사용한다고 자동으로 이 제한에서 제외된다고 볼 수 없습니다. 본 초안은 캐릭터·작품 소개와 준비 중인 프로젝트를 중심으로 만들었으며 결제, 장바구니, 회원가입, 주문 수집 기능을 넣지 않았습니다. 이것이 GitHub의 개별 사이트 적합성 승인을 뜻하지는 않습니다.

상점과 구매 유도가 사이트의 중심이 되는 단계에는 적합한 호스팅을 검토하세요. HTML/CSS/JS 형태이므로 다른 정적 호스팅에도 옮길 수 있습니다. 외부 판매처의 수수료·제작비·배송비 등은 각 서비스의 당시 정책에 따라 별도로 발생할 수 있습니다. 이 초안 제작에 판매처 계정 개설·결제 연동은 포함하지 않았습니다.

공식 근거: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

## 최종 적용에 필요한 자료

- 김호랑·호기 최신 원화 또는 투명 배경 PNG
- 공식 로고가 있다면 SVG 또는 PNG
- 확정된 스토어·작품별 링크
- 유지할 소개 문구와 실제 공개 가능한 작업물

캐릭터와 소개 문구를 검토한 뒤 적용하세요. 새로운 페이지, 구매 기능, 공개 배포는 하지 않았습니다.

## 검증 범위

HTML의 중복 ID, 내부 메뉴 연결, 이미지·CSS·JS 경로, 이미지 대체 텍스트, 빈 링크 여부와 JavaScript 문법을 확인했습니다. 미리보기 서버 실행 권한 및 브라우저 연결의 환경 제한으로 실제 PC·모바일 렌더링과 클릭 동작은 검증하지 못했습니다. 반응형 CSS와 상호작용은 구현되어 있지만, 최종 적용 전에 브라우저에서 확인해야 합니다.
